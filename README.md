# (C팀): (프로젝트 그룹 IZ*ONE(아이즈원)의 데뷔 이전부터 해체 후까지의 멤버들의 활동 네트워크)

## 1. 프로젝트 소개
우리 팀은 **아이즈원의 나무위키** 자료를 바탕으로 아이즈원 멤버들의 데뷔 이전과 해체 후의 활동 이력과 소속사 및 그룹 간 관계를 지식그래프로 구축합니다.

## 2. 팀원
- 백주연 (영어영문학과) — 자료심층조사
- 봉문예 (영어영문학과) — PPT 제작
- 심예린 (불어불문학과) — 발표
- 유사라 (국어국문학과) — PPT 제작
